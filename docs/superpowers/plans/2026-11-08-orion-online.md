# Orion Online Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Put the owner's real Orion online, privately, at $0/month: Supabase free (data), Vercel Hobby (website), Cloudflare Worker + Durable Objects (gateway), with auto-deploy on merge to `main`, encrypted daily backups, and a one-time move of the inspiration library + taste board.

**Architecture:** A new `apps/gateway-worker` package runs the gateway on Cloudflare. It reuses the existing gateway's protocol, repository, auth and dispatch modules (exported from `apps/gateway` as `@meld/gateway/core`), adds a `DeviceHub` Durable Object for connector sockets (hibernation + alarm-driven dispatch) and a `CanvasRoom` Durable Object per canvas (tldraw `TLSocketRoom` on DO SQLite). `apps/gateway` stays as the local-dev/e2e gateway. GitHub Actions deploy database → gateway → website after CI passes.

**Tech Stack:** Cloudflare Workers + Durable Objects (Wrangler), `@tldraw/sync-core` 5.3.0, `@supabase/supabase-js` 2.109.0, Next.js 16 on Vercel, Supabase CLI 2.109.1, GitHub Actions, `age` encryption, Node 22.23.2, pnpm 10.28.1, vitest 4.1.10.

**Spec:** `docs/superpowers/specs/2026-11-08-orion-online-design.md`

## Global Constraints

- Cost: every service on its free tier — Supabase Free, Vercel Hobby, Cloudflare Workers Free. No domain.
- Supabase CLI is exactly **2.109.1**. Never run `supabase db reset` against the hosted project; only `supabase db push`.
- Node **22.23.2**, pnpm **10.28.1**. New dependencies are pinned to exact versions (no `^`/`~`), matching the repo.
- The GitHub repository is **public**: no secret, dump content or personal data may appear in committed files or Actions logs. Backups are `age`-encrypted.
- Production secrets are freshly generated; never copy values from local `apps/web/.env.local`.
- Database changes are add-only; destructive SQL needs the marker comment `-- orion-allow-destructive`.
- Sign-ups are disabled after the owner's first sign-in.
- Do not re-pair the owner's installed `com.meld.agent` connector except in Task 12, which the owner performs.
- Plain-language summaries for the owner; they are not technical.

## Deviations from the spec (found while planning — record them in Task 10)

1. **No Postgres TCP in the Worker.** The gateway's task repository already talks to Supabase over HTTPS (`supabase.rpc`), and Postgres was only used for the canvas advisory lock, which Durable Objects make unnecessary. So the Worker has no `GATEWAY_DATABASE_URL` and no `postgres` dependency (spec B2 "Database" bullet and the B9 Worker secret are dropped).
2. **`apps/gateway` is not deleted in this project.** It remains the local-dev and Playwright canvas-trial gateway (its `/trial/*` endpoints and mutation-audit probe are test instruments used by `e2e/user-flow-trial.spec.ts`). The Worker ports only production behaviour. Spec delivery step 7 is deferred.
3. **No code change for the connector or Shelf URLs.** The connector CLI already honours `MELD_APP_URL` / `MELD_GATEWAY_URL` at pair time, and the Shelf's Connect screen already has an editable "Orion address" field that it stores. The runbook gives the exact commands instead (spec B6).
4. **tldraw licence.** tldraw requires a licence key for production (any HTTPS, non-localhost address). The free **hobby** licence (non-commercial, keeps the "made with tldraw" watermark) fits; it is discretionary, so the owner applies for it in Task 11. The web app already reads `NEXT_PUBLIC_TLDRAW_LICENSE_KEY`.

```ts
import { verifyCanvasSessionTicket, type CanvasSessionClaims } from "@meld/device-auth";
import type { AuthenticatedDeviceIdentity } from "@meld/gateway/core";

export const DEVICE_HEADER = "x-orion-device";
export const CANVAS_HEADER = "x-orion-canvas";

export interface CanvasConnect { claims: CanvasSessionClaims; sessionId: string }

export interface RouterDeps {
  authenticate(authorization: string | null): Promise<AuthenticatedDeviceIdentity | null>;
  canvasSecret: string;
  forwardToHub(request: Request, device: AuthenticatedDeviceIdentity): Promise<Response>;
  forwardToCanvas(request: Request, connect: CanvasConnect): Promise<Response>;
  now?: () => Date;
}

const CANVAS_PATH = /^\/canvas\/([^/]+)$/;

function json(body: unknown, status = 200): Response {
  return new Response(JSON.stringify(body), { status, headers: { "content-type": "application/json" } });
}

function isUpgrade(request: Request): boolean {
  return request.headers.get("Upgrade")?.toLowerCase() === "websocket";
}

export async function route(request: Request, deps: RouterDeps): Promise<Response> {
  const url = new URL(request.url);

  if (url.pathname === "/health") return json({ status: "ok" });

  if (url.pathname === "/ws") {
    if (!isUpgrade(request)) return json({ error: "Upgrade Required" }, 426);
    const device = await deps.authenticate(request.headers.get("Authorization"));
    if (!device) return json({ error: "Unauthorized" }, 401);
    return deps.forwardToHub(request, device);
  }

  const canvas = CANVAS_PATH.exec(url.pathname);
  if (canvas) {
    if (!isUpgrade(request)) return json({ error: "Upgrade Required" }, 426);
    const roomId = decodeURIComponent(canvas[1]!);
    let claims: CanvasSessionClaims;
    try {
      claims = verifyCanvasSessionTicket(
        url.searchParams.get("ticket") ?? "", deps.canvasSecret, roomId, deps.now?.() ?? new Date());
    } catch {
      return json({ error: "Unauthorized" }, 401);
    }
    const sessionId = url.searchParams.get("sessionId") ?? "";
    if (sessionId.length < 1 || sessionId.length > 200) return json({ error: "Unauthorized" }, 401);
    return deps.forwardToCanvas(request, { claims, sessionId });
  }

  return json({ error: "Not Found" }, 404);
}
```

import { Buffer } from "node:buffer";
import {
  createDispatchSweeper,
  createProtocolHandler,
  DeviceSession,
  DeviceSessionRegistry,
  type AuthenticatedDeviceIdentity,
  type DeviceSocket,
  type TaskRepository,
} from "@meld/gateway/core";

export interface HubSocketState { id: string; userId: string; lastHeartbeatAt: number }

interface DeviceHubCoreOptions {
  repository: TaskRepository;
  heartbeatSeconds: number;
  now?: () => number;
  onError?: (error: unknown) => void;
}

export class DeviceHubCore {
  private readonly registry = new DeviceSessionRegistry();
  private readonly sessions = new Map<DeviceSocket, DeviceSession>();
  private readonly sweeper;
  private readonly protocol;
  private readonly now: () => number;
  private readonly onError: (error: unknown) => void;

  constructor(private readonly options: DeviceHubCoreOptions) {
    this.now = options.now ?? Date.now;
    this.onError = options.onError ?? ((error) => console.error("Gateway hub error", error));
    // start() is never called: the Durable Object alarm drives sweep() instead.
    this.sweeper = createDispatchSweeper({
      repository: options.repository, registry: this.registry, intervalMs: 1, onError: this.onError,
    });
    this.protocol = createProtocolHandler({ repository: options.repository });
  }

  private add(socket: DeviceSocket, device: AuthenticatedDeviceIdentity, lastHeartbeatAt: number): DeviceSession {
    const session = new DeviceSession(device, socket);
    session.markHeartbeat(lastHeartbeatAt);
    this.sessions.set(socket, session);
    this.registry.add(session);
    return session;
  }

  restore(socket: DeviceSocket, state: HubSocketState): void {
    if (this.sessions.has(socket)) return;
    this.add(socket, { id: state.id, userId: state.userId }, state.lastHeartbeatAt);
  }

  async connect(socket: DeviceSocket, device: AuthenticatedDeviceIdentity): Promise<void> {
    const session = this.add(socket, device, this.now());
    session.send({ type: "session.accepted", heartbeatSeconds: this.options.heartbeatSeconds });
    try {
      await this.sweeper.sweepDevice(device.id);
    } catch (error) {
      this.onError(error);
      session.close(1011, "Device connection handler failed");
    }
  }

  async message(socket: DeviceSocket, data: string | ArrayBuffer): Promise<void> {
    const session = this.sessions.get(socket);
    if (!session) {
      socket.close(1011, "Unknown device session");
      return;
    }
    const frame = typeof data === "string" ? Buffer.from(data, "utf8") : Buffer.from(new Uint8Array(data));
    const before = session.lastHeartbeatAt;
    try {
      await session.enqueueMessage(() => this.protocol.handle(session, frame));
    } catch (error) {
      this.onError(error);
      session.close(1011, "Device message handler failed");
    }
    // DeviceSession.markHeartbeat() uses Date.now(); re-stamp with the injected clock.
    if (session.lastHeartbeatAt !== before) session.markHeartbeat(this.now());
  }

  state(socket: DeviceSocket): HubSocketState | null {
    const session = this.sessions.get(socket);
    return session ? { id: session.deviceId, userId: session.userId, lastHeartbeatAt: session.lastHeartbeatAt } : null;
  }

  remove(socket: DeviceSocket): void {
    const session = this.sessions.get(socket);
    if (!session) return;
    this.sessions.delete(socket);
    this.registry.remove(session);
  }

  async tick(): Promise<boolean> {
    this.registry.closeStaleSessions(this.now(), this.options.heartbeatSeconds * 2_000);
    for (const [socket, session] of this.sessions) {
      if (!session.isOpen) this.sessions.delete(socket);
    }
    try {
      await this.sweeper.sweep();
    } catch (error) {
      this.onError(error);
    }
    return this.sessions.size > 0;
  }
}

import { DeviceHubCore, type HubSocketState } from "./device-hub-core";
import { createSupabase, positiveInt, type Env } from "./env";

export class DeviceHub extends DurableObject<Env> {
  private core: DeviceHubCore | undefined;
  private leaseChecked = false;

  private hub(): DeviceHubCore {
    if (!this.core) {
      this.core = new DeviceHubCore({
        repository: createTaskRepository(createSupabase(this.env)),
        heartbeatSeconds: positiveInt(this.env.GATEWAY_HEARTBEAT_SECONDS, "GATEWAY_HEARTBEAT_SECONDS"),
      });
      // Woken from hibernation: rebuild sessions from socket attachments.
      for (const socket of this.ctx.getWebSockets()) {
        const state = socket.deserializeAttachment() as HubSocketState | null;
        if (state) this.core.restore(socket, state);
      }
    }
    return this.core;
  }

  private async checkLease(): Promise<void> {
    if (this.leaseChecked) return;
    const repository = createTaskRepository(createSupabase(this.env));
    assertHeartbeatWithinLease({
      heartbeatSeconds: positiveInt(this.env.GATEWAY_HEARTBEAT_SECONDS, "GATEWAY_HEARTBEAT_SECONDS"),
      leaseSeconds: await repository.getAiTaskLeaseSeconds(),
    });
    this.leaseChecked = true;
  }

  private async ensureAlarm(): Promise<void> {
    if ((await this.ctx.storage.getAlarm()) === null) {
      await this.ctx.storage.setAlarm(Date.now() + positiveInt(this.env.GATEWAY_POLL_INTERVAL_MS, "GATEWAY_POLL_INTERVAL_MS"));
    }
  }

  async fetch(request: Request): Promise<Response> {
    await this.checkLease();
    const device = JSON.parse(request.headers.get(DEVICE_HEADER) ?? "null") as AuthenticatedDeviceIdentity | null;
    if (!device) return new Response("Bad Request", { status: 400 });
    const pair = new WebSocketPair();
    const [client, server] = Object.values(pair) as [WebSocket, WebSocket];
    this.ctx.acceptWebSocket(server);
    const state: HubSocketState = { id: device.id, userId: device.userId, lastHeartbeatAt: Date.now() };
    server.serializeAttachment(state);
    this.ctx.waitUntil(this.hub().connect(server, device));
    await this.ensureAlarm();
    return new Response(null, { status: 101, webSocket: client });
  }

  async webSocketMessage(socket: WebSocket, message: string | ArrayBuffer): Promise<void> {
    const hub = this.hub();
    await hub.message(socket, message);
    const state = hub.state(socket);
    if (state) socket.serializeAttachment(state);
  }

  async webSocketClose(socket: WebSocket): Promise<void> {
    this.hub().remove(socket);
  }

  async webSocketError(socket: WebSocket): Promise<void> {
    this.hub().remove(socket);
  }

  async alarm(): Promise<void> {
    if (await this.hub().tick()) await this.ensureAlarm();
  }
}

import { readFileSync } from "node:fs";

const MARKER = "-- orion-allow-destructive";
const PATTERNS = [
  /\bdrop\s+table\b[^;]*/gi,
  /\bdrop\s+schema\b[^;]*/gi,
  /\balter\s+table\b[^;]*?\bdrop\s+(column|constraint)\b[^;]*/gi,
  /\btruncate\b[^;]*/gi,
  /\bdelete\s+from\b[^;]*/gi,

function stripComments(sql) {
  return sql.replace(/\/\*[\s\S]*?\*\//g, "").replace(/--[^\n]*/g, "");
}

export function findDestructiveStatements(sql) {
  if (sql.includes(MARKER)) return [];
  const body = stripComments(sql);
  return PATTERNS.flatMap((pattern) => [...body.matchAll(pattern)].map((m) => m[0].trim().slice(0, 120)));
}

    }
  }

```js
export const MOVED_TABLES = [
  "inspiration_items", "inspiration_labels", "taste_profiles",
  "taste_suggestions", "design_system_profiles", "design_system_profile_versions",
];

const USER_COLUMNS = ["created_by", "user_id"];
const PATH_COLUMNS = ["storage_path", "source_object_path"];

export function rewriteStoragePath(path, ids) {
  if (path == null) return path;
  const prefix = `${ids.sourceWorkspaceId}/`;
  return path.startsWith(prefix) ? `${ids.targetWorkspaceId}/${path.slice(prefix.length)}` : path;
}

export function rewriteRow(table, row, ids) {
  if (!MOVED_TABLES.includes(table)) throw new Error(`Not a moved table: ${table}`);
  if ("workspace_id" in row && row.workspace_id !== ids.sourceWorkspaceId) {
    throw new Error(`${table}: row from unexpected workspace ${row.workspace_id}`);
  }
  const out = { ...row };
  if ("workspace_id" in out) out.workspace_id = ids.targetWorkspaceId;
  for (const column of USER_COLUMNS) {
    if (column in out && out[column] != null) {
      if (out[column] !== ids.sourceUserId) throw new Error(`${table}.${column}: unexpected user ${out[column]}`);
      out[column] = ids.targetUserId;
    }
  }
  for (const column of PATH_COLUMNS) {
    if (column in out) out[column] = rewriteStoragePath(out[column], ids);
  }
  return out;
}
```

- [ ] **Step 6: Implement `move-data.mjs`** (I/O; uses `postgres` — run with `pnpm --filter @meld/gateway exec node ../../scripts/orion-online/move-data.mjs` so the gateway's `postgres` dependency resolves, or add `postgres@3.4.9` to the root devDependencies; pick the latter and pin it):

```js
#!/usr/bin/env node
import { createHash } from "node:crypto";
import postgres from "postgres";
import { MOVED_TABLES, rewriteRow } from "./move-data-plan.mjs";

const env = (name) => { const v = process.env[name]; if (!v) throw new Error(`Missing ${name}`); return v; };
const source = postgres(env("SOURCE_DB_URL"), { max: 1 });
const target = postgres(env("TARGET_DB_URL"), { max: 1, prepare: false });

const BUCKETS = { inspiration_items: ["inspiration", "storage_path"],
  design_system_profile_versions: ["design-system", "source_object_path"] };

async function single(sql, query, label) {
  const rows = await sql.unsafe(query);
  if (rows.length !== 1) throw new Error(`${label}: expected exactly 1, found ${rows.length}`);
  return rows[0];
}

async function download(base, key, bucket, path) {
  const res = await fetch(`${base}/storage/v1/object/${bucket}/${path}`, { headers: { Authorization: `Bearer ${key}`, apikey: key } });
  if (!res.ok) throw new Error(`download ${bucket}/${path}: ${res.status}`);
  return { bytes: new Uint8Array(await res.arrayBuffer()), type: res.headers.get("content-type") ?? "application/octet-stream" };
}

async function upload(base, key, bucket, path, file) {
  const res = await fetch(`${base}/storage/v1/object/${bucket}/${path}`, {
    method: "POST", body: file.bytes,
    headers: { Authorization: `Bearer ${key}`, apikey: key, "content-type": file.type, "x-upsert": "true" } });
  if (!res.ok) throw new Error(`upload ${bucket}/${path}: ${res.status} ${await res.text()}`);
}

const sha = (bytes) => createHash("sha256").update(bytes).digest("hex");

try {
  const src = await single(source, "select distinct workspace_id, created_by from inspiration_items", "source owner");
  const tgtUser = await single(target, "select id from auth.users", "target user");
  const tgtWs = await single(target, "select id from public.workspaces", "target workspace");
  const ids = { sourceWorkspaceId: src.workspace_id, sourceUserId: src.created_by,
    targetWorkspaceId: tgtWs.id, targetUserId: tgtUser.id };

  for (const table of MOVED_TABLES) {
    const rows = await source.unsafe(`select * from public.${table} where workspace_id = $1`, [ids.sourceWorkspaceId]);
    let copied = 0;
    for (const row of rows) {
      const next = rewriteRow(table, row, ids);
      const bucket = BUCKETS[table];
      if (bucket && row[bucket[1]]) {
        const file = await download(env("SOURCE_SUPABASE_URL"), env("SOURCE_SERVICE_KEY"), bucket[0], row[bucket[1]]);
        await upload(env("TARGET_SUPABASE_URL"), env("TARGET_SERVICE_KEY"), bucket[0], next[bucket[1]], file);
        const back = await download(env("TARGET_SUPABASE_URL"), env("TARGET_SERVICE_KEY"), bucket[0], next[bucket[1]]);
        if (sha(back.bytes) !== sha(file.bytes)) throw new Error(`hash mismatch ${bucket[0]}/${next[bucket[1]]}`);
      }
      const result = await target`insert into ${target("public." + table)} ${target(next)} on conflict do nothing`;
      copied += result.count;
    }
    const [{ count }] = await target.unsafe(`select count(*)::int as count from public.${table} where workspace_id = $1`, [ids.targetWorkspaceId]);
    if (count < rows.length) throw new Error(`${table}: target has ${count}, source has ${rows.length}`);
    console.log(`${table.padEnd(32)} ${rows.length} in source · ${copied} newly copied · ${count} online ✓`);
  }
} finally {
  await source.end();
  await target.end();
}
```

Note `target("public." + table)` — postgres.js treats a dotted string as schema-qualified identifier. If the table has a generated column or trigger that rejects explicit values (check the `\d` output from Step 1), drop that column from `next` before insert and say so in the commit message.
